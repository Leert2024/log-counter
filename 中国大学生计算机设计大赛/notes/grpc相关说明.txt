数据类型：
	string			字符串类型
	bytes			比特类型
	bool 			布尔类型
	int32 			32位整形
	int64 			64位整形（python 3中所有整形都为64位整形）
	float 			浮点类型
	repeated 		数组（python 列表）repeated string data = 1
	map 			映射（python词典）map<string, string> data = 1

关键字：
	package 		包名
	syntax Protobuf	版本
	service			定义服务
	rpc				定义服务中的方法
	stream			定义的方法传输为流传输
	message			定义消息体 message User{}
	extend			扩展消息体 extend User{}
	import			导入插件
	//				注释

_pb2.py文件储存每一个message对应的信息
_pb2_grpc.py文件储存每个服务的server和客户端，以及注册server的工具
客户端名称：service_name + Stub
服务器名称：service_name + Servicer
注册服务为：add_服务端名_to_server

由proto文件生成py文件的命令：
	python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. user.proto
